:::caution

We strongly **recommend** to use the [IW4x Launcher](https://github.com/iw4x/launcher) described in the [Quickstart Guide](/get-started/quickstart).  
It's the easiest and most reliable way to install and keep IW4x up to date  
However, if you prefer to install IW4x manually, you can follow the steps outlined below.  
**Important**: If you manually install IW4x, you'll need to repeat all of these steps each time a new update is released.

:::

Since the PC version of Modern Warfare 2 was never released on Linux systems, installing is a little bit trickier.  

Today, two practical ways exist:

[**Method 1:**](#1-using-proton) Using **[Proton](https://github.com/ValveSoftware/Proton)**, Steam's built-in compatibility layer.  
[**Method 2:**](#2-using-wine-prefix) Using a **[custom Wine prefix](https://www.winehq.org/)**, managed by the user.

Just like on [Windows](/get-started/manual-install/windows-guide/), both approaches require IW4x to be installed in the game directory of MW2.

### 1. Using Proton

Steam now enables Proton for Windows-only titles by default.  
This means that, once installed through Steam, Modern Warfare 2 is ready to go with no special configuration required.  
Installing IW4x then only requires downloading and extracting the necessary files into the MW2 Proton directory.

For example, assuming `$STEAMLIBRARY` points to your Steam library, IW4x can be installed with the following commands:

<Steps>

1. **Download `iw4x.dll`**

   ```bash
   curl -L https://github.com/iw4x/iw4x-client/releases/latest/download/iw4x.dll -o iw4x.dll
   ```

2. **Download `raw files` and `iw4x.exe`**

   ```bash
   curl -L https://github.com/iw4x/iw4x-rawfiles/releases/latest/download/release.zip -o release.zip
   ```

3. **Extract archive**

    ```bash
    unzip -o release.zip -d "$STEAMLIBRARY/steamapps/common/Call of Duty Modern Warfare 2"
    ```

4. **Install the optional DLC files**

   The additional DLC files are not included in `release.zip`. Download the DLC manifest, then install each file in the appropriate MW2 directory:

   ```bash
   GAME_DIR="$STEAMLIBRARY/steamapps/common/Call of Duty Modern Warfare 2"

   mkdir -p "$GAME_DIR/main" "$GAME_DIR/zone/dlc"

   curl -L https://cdn.iw4x.io/update.json -o dlcs.json

   jq -r \
     '.files[]
      | select(.path | test("\\.(iwd|ff)$"))
      | [.path, .asset_name, .blake3]
      | @tsv' \
     dlcs.json |
   while IFS="$(printf '\t')" read -r path name checksum; do
     case "$name" in
       *.iwd) destination="$GAME_DIR/iw4x/$name" ;;
       *.ff)  destination="$GAME_DIR/zone/dlc/$name" ;;
     esac

     curl -L "https://cdn.iw4x.io/$path" -o "$destination"
     printf '%s  %s\n' "$checksum" "$destination" | b3sum --check
   done

   rm -f dlcs.json
   ```

   This step requires `jq` and `b3sum`.

</Steps>

From there, Add IW4x to your Steam library as a non-Steam game. Once added, right-click the IW4x entry and select Properties. Under Compatibility, enable Force the use of a specific Steam Play compatibility tool, then select Proton Experimental.

IW4x can then be launched directly from its Steam library entry. Steam will start it through Proton and provide the required Windows compatibility environment.

### 2. Using Wine Prefix

Others prefer not to rely on Proton's managed environment. In that case, a dedicated Wine prefix must be created and configured. The process requires several steps, which are described below:

<Steps>

1. **Create a new prefix**

   ```bash
   WINEPREFIX=~/.wine-mw2 wineboot
   ```

2. **Install required runtimes**

   IW4x and Modern Warfare 2 expect a number of Microsoft libraries to be present.  
   These can be installed with `winetricks`:

   ```bash
   WINEPREFIX=~/.wine-mw2 winetricks vcrun2019 d3dcompiler_47 dxvk
   ```

3. **Acquire Modern Warfare 2**

   The game can be installed through Steam running inside that prefix.  
   Or, alternatively, by retrieving the files directly using [`DepotDownloader`](https://github.com/SteamRE/DepotDownloader):

   ```bash
   ./DepotDownloader -app 10190 -username <username> -password <password>
   ```

4. **Add IW4x**

   With the base game in place, the IW4x files can be downloaded into the prefix's game directory:

    ```bash
    curl -L https://github.com/iw4x/iw4x-client/releases/latest/download/iw4x.dll -o iw4x.dll
    curl -L https://github.com/iw4x/iw4x-rawfiles/releases/latest/download/release.zip -o release.zip
    unzip -o release.zip -d ~/.wine-mw2/drive_c/Program\ Files/Steam/steamapps/common/Call\ of\ Duty\ Modern\ Warfare\ 2
    ```

5. **Install the optional DLC files**

   ```bash
   GAME_DIR="$HOME/.wine-mw2/drive_c/Program Files/Steam/steamapps/common/Call of Duty Modern Warfare 2"

   mkdir -p "$GAME_DIR/main" "$GAME_DIR/zone/dlc"

   curl -L https://cdn.iw4x.io/update.json -o dlcs.json

   jq -r \
     '.files[]
      | select(.path | test("\\.(iwd|ff)$"))
      | [.path, .asset_name, .blake3]
      | @tsv' \
     dlcs.json |
   while IFS="$(printf '\t')" read -r path name checksum; do
     case "$name" in
       *.iwd) destination="$GAME_DIR/iw4x/$name" ;;
       *.ff)  destination="$GAME_DIR/zone/dlc/$name" ;;
     esac

     curl -L "https://cdn.iw4x.io/$path" -o "$destination"
     printf '%s  %s\n' "$checksum" "$destination" | b3sum --check
   done

   rm -f dlcs.json
   ```

   This step requires `jq` and `b3sum`.

</Steps>

Once the base game is present and the IW4x files downloaded and extracted, we are ready to run the game.  
All you have to do is invoking Wine explicitly:

```bash title="bash"
WINEPREFIX=~/.wine-mw2 wine iw4x.exe
```

Though more involved, this method grants precise control over the runtime environment, which some users may prefer.

## Install using POSIX Shell Script

One of our awesome community members maintains script that automates installing and updating IW4x on Linux and other unix-likes!
You can check it out here: https://github.com/kkrruumm/iw4x-updoot  
Make sure to read through their README for usage instructions and details.
